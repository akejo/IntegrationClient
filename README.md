# IntegrationClient

A desktop tool for testing REST, SOAP and external program integrations.

This is the public home of IntegrationClient: downloads (see [Releases](../../releases)), bug reports, feature requests and discussions. The source code is private.

The "Source code (zip / tar.gz)" files on each release are added by GitHub automatically. They contain this repository's files (this README and the issue forms), not IntegrationClient's source code.

## Reporting a bug or asking for a feature

- **Bug:** [open a bug report](../../issues/new?template=bug_report.yml)
- **Idea or improvement:** [open a feature request](../../issues/new?template=feature_request.yml)
- **Question or "how do I…":** ask in [Discussions](../../discussions)

Please search existing issues first, your problem may already be known.

## Keep secrets out

Everything here is **public**. Before posting logs, config or screenshots, remove:

- client IDs, client secrets, tokens and passwords
- real hostnames, IP addresses and URLs of your services
- request or response bodies that contain personal or customer data

The **Normal** log view is usually enough. If you share a **Debug** log, read it through first: it includes request bodies and response data.
